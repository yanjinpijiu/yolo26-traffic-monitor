## 任务清单

### Task 1: 搭建新 GUI 骨架（窗口布局 + 控件占位）

**目标：** 建立完整的窗口布局，所有控件先放上去，功能后续逐个接线。

**要做的事：**
1. 重写 gui_app.py，建立完整布局：
   - 左侧：视频画面 QLabel
   - 右侧控制面板：
     - 输入源选择（文件 / 摄像头）
     - 模型路径选择
     - 播放控制（开始、暂停/继续、停止）
     - 置信度阈值滑块 (0.1~0.9，默认0.4)
     - 检测线位置滑块 (0.1~0.9，默认0.6)
     - 实时统计（总数、上行、下行、FPS、帧数）
     - 各类别计数（car/bus/van/truck/others）
     - CSV导出按钮
     - 系统日志 QTextEdit
2. 搬入 TrackManager 和 Counter 类（从 count_vehicles_v2.py 复制）
3. VideoThread 改造：支持视频文件和摄像头两种输入

**验证：** 运行 `python gui_app.py`，窗口能正常显示，所有控件可见，选择视频文件后点开始能跑。

---

### Task 2: 接线置信度滑块 + 检测线滑块

**目标：** 滑块实时调节检测参数。

**要做的事：**
1. 置信度滑块：改变 CONF_THRESHOLD，传给 model.track(conf=...)
2. 检测线滑块：改变 COUNT_LINE_RATIO，重算 count_line_y，画面实时更新红线位置
3. 滑块值变化时在日志区输出提示

**验证：** 拖动置信度滑块，日志输出新阈值；拖动检测线滑块，视频画面上红线位置实时变化。

---

### Task 3: 暂停/继续 + 进度条

**目标：** 视频播放可暂停、可拖进度跳转。

**要做的事：**
1. 暂停/继续按钮：VideoThread 内用 self.paused 标志控制循环
2. 进度条 QSlider：显示当前帧/总帧数，拖动时 seek 到指定帧
3. 按钮文字切换：暂停时显示"继续"，播放时显示"暂停"

**验证：** 播放视频时点暂停画面冻结，点继续恢复；拖进度条跳到指定位置。

---

### Task 4: 轨迹线显示

**目标：** 在视频画面上画出车辆运动轨迹。

**要做的事：**
1. VideoThread 处理每帧时，调用 TrackManager 的 get_last_n_positions 画轨迹线
2. 轨迹颜色渐变（旧→新从暗到亮）
3. 用 active_ids 只画当前帧存在的目标轨迹

**验证：** 播放视频时能看到车辆身后拖着渐变色轨迹线。

---

### Task 5: 摄像头输入

**目标：** 支持实时摄像头检测。

**要做的事：**
1. 输入源区域加"摄像头"按钮
2. 点击后用 cv2.VideoCapture(0) 打开默认摄像头
3. 摄像头模式下隐藏进度条（实时流无总帧数）
4. 日志区输出"摄像头已打开"

**验证：** 点摄像头按钮，实时画面显示在界面上，检测正常运行。

---

### Task 6: CSV 导出

**目标：** 把统计数据导出为 CSV 文件。

**要做的事：**
1. 点"导出CSV"按钮，弹出文件保存对话框
2. 写入：时间戳、总车流量、上行、下行、各类别数量、平均FPS
3. 日志区输出导出路径

**验证：** 点导出，选择路径，打开 CSV 文件内容正确。

---

### Task 7: 系统日志完善

**目标：** 日志区实时输出关键事件。

**要做的事：**
1. 所有操作写日志：模型加载、视频打开、开始/暂停/停止、参数变化、计数变化、导出
2. 日志带时间戳，自动滚动到底部
3. 日志区只读

**验证：** 操作过程中日志区实时显示所有事件。

---

### Task 8: 宽高比辅助校正 + 计数优化完善

**目标：** 补齐课程要求的最后一项优化策略。

**要做的事：**
1. Counter.check_crossing 中增加宽高比检查：
   - 计算 box 的 aspect_ratio = width / height
   - 车辆通常宽>高 (ratio > 1)，如果 ratio < 0.5 可能是误检，跳过
2. 在 TrackManager 中记录每个 track 的 aspect_ratio 历史，取中位数判断

**验证：** 检测结果中不会把明显不是车辆的细长目标计数。
